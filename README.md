# 전병룡 포트폴리오

기구설계 및 시스템 개발 포트폴리오입니다. SHW-120, SHW-130, SDC MANUAL JIG SERIES, MONITOR-MINI-ESS의 4개 프로젝트를 담았습니다.

- [포트폴리오 웹사이트](https://jeonbyungryong.github.io/jby-portfolio/)
- [최종 포트폴리오 PDF](docs/portfolio.pdf)

웹사이트 링크는 GitHub Pages 설정과 최초 배포가 완료된 후 사용할 수 있습니다. 이 파일 묶음 자체가 배포 성공을 의미하지 않습니다.

## 열람

PC에서는 휠 한 동작에 한 장씩 이동합니다. 모바일에서는 현재 장의 긴 내용을 먼저 읽고 다음 장으로 이동합니다. 하단 이전·다음 버튼과 페이지 선택, 이미지 확대, 전체 읽기 모드를 사용할 수 있습니다.

## 공개 파일

`docs/`는 검토된 정적 웹 파일과 PDF입니다. 원본 PPT, 발표자 노트, 개발 문서, 과거 개인정보 자료와 인증정보는 포함하지 않습니다.

## 최초 게시 설정

Settings → Pages → Deploy from a branch → `main` → `/docs`.
완성된 파일을 사용하며 ZIP을 그대로 업로드해 자동 추출하는 방식이 아닙니다.
