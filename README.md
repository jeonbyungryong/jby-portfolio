## 마지막 게시 설정

[GitHub Pages 설정 열기](https://github.com/jeonbyungryong/jby-portfolio/settings/pages)

Build and deployment에서 Source를 **Deploy from a branch**, Branch를 **main**, 폴더를 **/docs**로 선택한 뒤 **Save**합니다. 파일을 다시 올리거나 ZIP을 풀 필요가 없습니다. 실제 게시 성공과 홈페이지 접속을 확인한 뒤 운영 상태를 갱신합니다.

## 열람 방식

PC에서는 휠 한 동작에 한 장씩 이동합니다. 모바일에서는 현재 장의 긴 내용을 먼저 읽고 다음 장으로 이동합니다. 하단 이전·다음 버튼과 페이지 선택, 이미지 확대, 전체 읽기 모드를 사용할 수 있습니다. 실제 모바일·카카오톡에서의 공개 페이지 검수는 활성화 후 확인합니다.

## 공개 파일과 검증

`docs/`는 검토된 정적 웹 파일과 PDF입니다. 원본 PPT, 발표자 노트, 개발 문서, 과거 개인정보 자료, 인증정보와 폰트 파일은 포함하지 않습니다. 임시 전송용 OneDrive 파일은 전송 후 휴지통으로 삭제했습니다. 사이트는 해당 임시 링크에 의존하지 않습니다.
